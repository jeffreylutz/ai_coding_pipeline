# Autonomous Agentic Coding

The goal of this project is to create complete coding pipelines with integration with Git and Jira.  Then developers would only need to write Jira stories and review specifications and the agentic pipeline would create the code and open PRs for review.


## Development containers

[Base container image](https://github.com/Dicklesworthstone/agentic_coding_flywheel_setup)  
From zero to fully-configured agentic coding VPS in 30 minutes. A complete bootstrapping system that transforms a fresh Ubuntu VPS into a professional AI-powered development environment.

## Multi-agent coding pipelines

[Kiro Autonomous Agent](https://kiro.dev/autonomous-agent/)  
Kiro autonomous agent is a frontier agent that works independently on development tasks, maintaining context and learning from every interaction.

[Auto-Claude](https://github.com/AndyMik90/Auto-Claude)  
Autonomous multi-agent coding frameowrk that plans, builds, and validates software for you.

[Continuous-Claude](https://github.com/parcadei/Continuous-Claude-v2)  
Session continuity, token-efficient MCP execution, and agentic workflows for Claude Code.

[Automaker](https://github.com/AutoMaker-Org/automaker?tab=readme-ov-file#the-workflow)  
Automaker is an autonomous AI development studio that transforms how you build software.

[InfiAgent](https://github.com/ChenglinPoly/infiAgent)  
infiAgent Also called MLA (Multi-Level Agent) is an agent framework designed for unlimited runtime without tool calling chaos or system crashes caused by cumulative task resources and conversation history. With MLA, you can build powerful general-purpose and semi-specialized agents simply by writing configuration files.

[MAI-UI](https://github.com/Tongyi-MAI/MAI-UI)  
MAI-UI, a family of GUI agent foundation models spanning the full spectrum of sizes, including 2B, 8B, 32B, and 235B-A22B variants.
